Open `index.html` in Chrome, Safari, or Firefox. This is a plain white single-page portfolio with chibi illustration poses and scroll-controlled changes. **These are animated 2D poses, not a fully rigged 3D character.**

Sections: Home, About, Education (FAU 3.77/4.0, Raghu 9.3/10), DSA Mentorship with Smart Interviews, four detailed projects, categorized skills, and Contact.

The shortened LinkedIn links for the hospital app and LangChain demo were supplied by the user; if they do not redirect correctly, replace them with final destination URLs. The bachelor's degree dates and listed GPAs were user-supplied. The MS end date is marked expected.

To deploy: upload the full folder (including `assets`) to a static hosting service such as GitHub Pages, Netlify, or Vercel.
