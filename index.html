01 / AGENTIC AI

Agentic AI Chatbots with LangGraph

Developed an end-to-end Agentic AI application as part of my coursework, progressing from a basic chatbot to a tool-using assistant and an AI news summarizer. The application combines LLM responses with real-time external information and an interactive web interface.

What I implemented

  • Basic conversational chatbot with Groq-powered LLM responses.
  • Tavily web search invoked through LangGraph tool-calling and conditional routing.
  • Stateful message handling through nodes, edges, graph state, and tool decisions.
  • AI News Summarizer that supports daily, weekly, and monthly summaries.
  • Streamlit interface, with a deployed application on Render.

What I learned: How an agent decides to call a tool, incorporates its response, and produces a final answer. I also worked through challenges involving message state, tool integration, model limits, session state, debugging, and deployment.

02 / NLP & APPLIED AI

AI Support Ticket Intelligence Platform

Built an end-to-end AI system designed to help customer support teams analyze incoming requests, understand customer needs, retrieve relevant previous cases, and draft contextual responses.

Pipeline and features

Ticket → Classification → Priority → Sentiment → Summarization → Semantic Search → Suggested Response

  • Classifies support tickets into categories and predicts their priority.
  • Detects customer sentiment and produces concise ticket summaries.
  • Uses embeddings and cosine similarity to retrieve related historical tickets.
  • Generates suggested responses informed by retrieved ticket context.
  • Combines fine-tuned and pretrained NLP models within an interactive Gradio application.

What I learned: Model fine-tuning, transformer-based NLP, semantic retrieval, prompt design, and integrating multiple AI components into one application pipeline.
